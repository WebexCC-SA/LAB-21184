# Congratulations
Your journey does not need to end here, you have just started to scratch the surface of what is possible with Spec Driven Development and Spec Kit.  In this lab we focused on creating a net new integration project, but you can also bring Spec Kit into existing projects to add additional functionality, use Spec Kit for bug fixing, and even use Spec Kit for idea assessment.  
While you were using Copilot for this lab, Spec Kit supports 41 different AI Coding Agent Integrations including a generic option, and you have the option to easily change from one AI Agent Integration to another so you are never locked into a specific AI Agent Integration.  
For more information on Spec Kit check out the [Spec Kit Documentation.](https://github.github.io/spec-kit/){:target="_blank"}  

## If you decide to continue working on this project after Webex One
> Make sure that you remove the hook-to-socket tool from the spec as it was only created to help with the live delivery of this lab and will be taken down after the conclusion of the event.  For local development you can use tools like Ngrok to provide a connection point for your webhooks and when you host your code on a service you will point your webhooks to the hosted service.
